# 喵绘插件下载

本仓库分发插件安装包、更新说明和兼容性信息。源码保存在独立非公开仓库。

## NovelAI 0.3.3

在喵绘“窗口 → 外置插件 → GitHub 插件来源”中添加 **`anjaymi/miaohui-plugins`**，检查更新并安装 NovelAI。

也可在 [Releases](https://github.com/anjaymi/miaohui-plugins/releases/latest) 下载 Windows x64 插件 ZIP，再从喵绘导入。

**需要喵绘 0.369.0 或更新版本 / Host API 1，并且宿主支持 `canvas.alphaPatch` 与专用蒙版编辑器。旧宿主请先更新喵绘。此下载只包含插件。**

- 按比例框选，标准尺寸生成、原位新图层回填；支持图生图与真正的蒙版局部重绘。
- 专用蒙版笔刷与独立上下文取景；修正最终蒙版和重绘强度转换，消除本次真实实测的灰圈。
- 多方案候选与原位预览；多角色提示词、可视化定位和历史复用。
- 固定/随机画师、画师方案、通配符、WD 反推和生成记录。
- 账户额度与可自定义外观；完整与精简面板共享任务和设置。
- 四页参数面板，模型可用项自动适配，V5 Variety+ 可用。

使用自己的 NovelAI 账号；额度和消耗以服务返回为准。更新保留宿主管理的个人数据。

公开 Release 提供插件 ZIP 与 `plugins.json`；业务源码保存在独立非公开仓库。许可见安装包内 LICENSE、THIRD-PARTY.md 和 licenses/。更新详情见 [CHANGELOG](CHANGELOG.md)。
