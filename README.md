# 喵绘插件下载

本仓库只分发插件安装包、更新说明和兼容性信息。

## NovelAI 0.2.8

在喵绘“窗口 → 外置插件 → GitHub 插件来源”中添加 **`anjaymi/miaohui-plugins`**，检查更新并安装 NovelAI。

也可在 [Releases](https://github.com/anjaymi/miaohui-plugins/releases/latest) 下载 Windows x64 插件 ZIP，再从喵绘导入。最低宿主版本：**0.365.0，Host API 1**。

- 按比例框选、盖印可见区域、标准尺寸生成与原位新图层回填。
- 固定/随机画师、画师方案、通配符、WD 反推与生成记录。
- 账户额度显示，完整与精简面板共享任务和设置。
- 四页参数面板，模型可用项自动适配；V5 Variety+可用。
- 参数预览、生成方案与实际请求一致，保留加权提示词语法。

用户使用自己的 NovelAI 账号；具体额度和消耗以服务返回为准。

公开 Release 提供插件 ZIP 与 `plugins.json`；业务源码保存在独立非公开仓库。插件自身与第三方组件的许可见安装包内 LICENSE、THIRD-PARTY.md 和 licenses/。
